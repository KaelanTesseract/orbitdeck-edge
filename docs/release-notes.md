## Orbitdeck Edge 0.9.0 – first release

**🇬🇧** A living space scene for the CORSAIR XENEON EDGE: a turning ringed planet behind a large clock, five scenes, tasks and focus sessions, calendar, timer, music with a real visualizer, up to 12 shortcuts, CPU/GPU/RAM/network and PC commands.

**🇩🇪** Eine lebendige Weltraum-Szene für die CORSAIR XENEON EDGE: ein sich drehender Ringplanet hinter einer großen Uhr, fünf Szenen, Aufgaben und Fokus-Sitzungen, Kalender, Timer, Musik mit echtem Visualizer, bis zu 12 Shortcuts, CPU/GPU/RAM/Netzwerk und PC-Befehle.

### Install / Installieren
1. Download and run `OrbitdeckEdge-Setup-0.9.0.exe` – Herunterladen und starten.
2. Follow the setup assistant – dem Einrichtungs-Assistenten folgen.

Guide / Anleitung: [README](https://github.com/KaelanTesseract/orbitdeck-edge#readme) · [Setup](https://github.com/KaelanTesseract/orbitdeck-edge/blob/main/docs/SETUP.md)

Requires Windows 10/11 (64-bit), iCUE 5.52+ and a XENEON EDGE (XL horizontal). The installer is not code-signed: Windows may ask you to confirm (*More info → Run anyway*). Checksums: `SHA256SUMS.txt`.

Planet textures: Solar System Scope (CC BY 4.0). Not affiliated with CORSAIR.
